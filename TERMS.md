## Optional site features

If GitHub sign-in is enabled, the API stores the GitHub account ID, username,
available profile name and email, avatar URL, profile URL, and account
timestamps. Session cookies are HTTP-only, and only a hash of each session
token is stored. The API does not store GitHub access tokens.

The music player stores visitor-selected tracks and saved links in that
visitor's browser. The site does not upload those files or links. Visitors are
responsible for having the rights to any media they select or share.

If configured, the profile-link counter records an aggregate number of clicks.
It is a link-click count, not a follower count. The API host and database
provider may process technical request metadata.
