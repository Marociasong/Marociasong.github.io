# Marociasong

A client website with links to Marociasong's social profiles:

- [Instagram](https://www.instagram.com/marociasong)
- [Facebook](https://www.facebook.com/profile.php?id=61590101694470)
- [YouTube](https://www.youtube.com/@marociasong)
- [TikTok](https://www.tiktok.com/@marociasong)

Music, videos, and other posts remain on their original platforms. This

repository does not include Marociasong audio, videos, or personal artwork.

## Development

```sh
npm ci
npm run dev
```

Create a production build with `npm run build`.
